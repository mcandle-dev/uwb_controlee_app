## T-2. 사양서 v0.3 개정 — 광고 Local Name (Android 플랫폼 제약)

사양서 §3은 광고 Local Name을 `UWB-OOB`로 **확정값**으로 박아 놨지만, **Android는 임의
광고 이름을 넣을 수 없다** — 어댑터(폰 블루투스) 이름만 포함 가능하다. 폰 BT 이름을 전역으로
바꾸는 건 부작용이 커서 하지 않았고, 현재 구현은 이름을 스캔 응답에 어댑터 이름으로 싣는다.

콘솔이 **Service UUID로 필터**하면 문제없지만, **이름으로 필터하면 폰을 못 찾는다.**

- 사양서 §3을 "필터 기준 = Service UUID. Local Name은 참고용(플랫폼에 따라 폰 BT 이름)"으로 개정
- 마스터(`radar_test_console/docs/oob/`) + 이 리포 사본을 **동시 커밋, 버전 업(v0.3)**
- 콘솔 쪽 스캔 필터가 이름에 의존하지 않는지 확인

## T-3. 실기기 검수 (nRF Connect) — 변경요구서 §3

아직 한 번도 실행하지 않았다. `adb install -r app/build/outputs/apk/debug/app-debug.apk` 후:

- [ ] 1. Start → BLE 권한 다이얼로그 → 허용 → 로그 "OOB 광고 시작" + 배지 `⚪ 광고중`
- [ ] 2. 다른 폰 nRF Connect 스캔에서 Service UUID `5F1D0001-9A8B-4C7D-B2E3-6F4A5D8C9B0A` 발견
       (이름은 폰 BT 이름으로 뜬다 — T-2 참조, 버그 아님)
- [ ] 3. 연결 → 배지 `🔵 콘솔 연결됨` + 광고 중지 → `5F1D0002-…` Read →
       7B가 `01 | 주소2B(화면 표시 순서) | 2A 00 00 00`과 일치 (바이트 순서 사양서 §4 그대로)
- [ ] 4. Notify 구독 → 로그 "OOB Notify 구독됨"
- [ ] 5. Stop → 광고 사라짐 + 연결 끊김 + 배지 사라짐, 로그 "OOB 종료"
- [ ] 6. Stop→재Start로 주소 변경 시 재연결 후 Read하면 새 주소 (FR-13.
       Stop이 GATT를 끊으므로 Notify는 세션 유지 중 재발급 케이스에서 확인)
- [ ] 7. **BLE 권한 거부 상태에서 Start → 주황 배너 뜨고 UWB 레인징은 정상 진행**
       (이게 핵심 — BLE 실패가 UWB를 막지 않는다는 원칙의 검수)
- [ ] 8. 로그 콘솔에 OOB 이벤트가 시각과 함께 남는다
